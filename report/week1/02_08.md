## <span style="color:#ADD8E6"> **Tema:** Estruturas de Dados em uma Empresa </span>

### **Introdução**

A Engenharia de Dados é responsável por estruturas de dados de uma empresa, sendo elas: 

1. Planejar as estruturas
2. Desenvolver
3. Manter tudo isso funcionando

### **Planejar e Desenvolver**

- **Data Warehouses:** Armazém de dados.
- **Data Lakes:** Armazém de dados modernos.
- **Processos de Análise (Batch):** Processamentos de grandes volumes de dados.
- **Streaming:** Dados que são produzidos em Streaming, e que são processados em tempo real.
- **Processos de ETL e ELT:** Processos de carga de dados.

### **Manter**

O que se espera dos dados da empresa, o que se espera que os dados tenham:

- **Disponibilidade:** Você não quer acessar uma informação indisponível, precisa ter disponibilidade da maneira que você precisar.
- **Confiabilidade:** Se você pede o faturamento de um cliente, as informações têm que ser confiáveis.
- **Segurança:** Os dados têm que ser seguros, sem vazamentos de informações do cliente ou próprios.
- **Planos de Contingência:** Problemas podem acontecer, algumas coisas podem falhar, e é necessário ter planos de contingência para que a disponibilidade seja mantida.

### **Responsabilidades do Profissional de Engenharia de Dados**

Além disso, o profissional de Engenharia de Dados precisa garantir:

- **Performance dos dados:** Os relatórios de alta gestão não podem demorar 2 horas, por exemplo, precisam ter boa performance.
- **Normas e Leis:** LGPD / Governança de Dados. A empresa deve aderir às normas e leis, tanto a Lei Geral de Proteção de Dados Pessoais quanto à política de governança de dados da própria empresa.

### **Conclusão**

Em resumo, o profissional de Engenharia de Dados desenvolve, opera e mantém estruturas de dados complexas e heterogêneas, sendo responsável pela segurança, integridade, disponibilidade e confiabilidade dos dados.
