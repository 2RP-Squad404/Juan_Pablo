## **Introdução**
A modelagem de dados envolve a construção de um modelo que descreve os tipos de dados usados, suas propriedades e os relacionamentos entre eles. Esses modelos podem ser divididos em três níveis principais:

### Modelo Conceitual
Representa uma visão geral dos dados, focando nas entidades principais e seus relacionamentos, sem detalhes técnicos.
### Modelo Lógico
Oferece uma visão mais detalhada, incluindo atributos, chaves primárias e estrangeiras, e outros aspectos que descrevem como os dados se conectam.
### Modelo Físico
Define como os dados serão fisicamente armazenados no banco de dados, detalhando tabelas, colunas e índices.
