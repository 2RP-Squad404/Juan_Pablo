## **Git**

O **Git** é um sistema de controle de versão que ajuda a manter o seu código organizado, permite voltar a versões anteriores, e facilita o trabalho em equipe.

### **O que é o Git?**

Git permite que você acompanhe as mudanças no seu código ao longo do tempo.

1. **Salvar o estado do seu código** em vários momentos (commits).
2. **Voltar para uma versão anterior** se algo der errado.
3. **Colaborar com outras pessoas** sem interferir no trabalho delas.

## **Comandos Básicos do Git**
### 1. Inicializar um Repositório Git

Para começar a usar o Git em um projeto, você precisa inicializar um repositório:

```
git init
```

### 2. Adicionar Arquivos ao Controle de Versão
Adicione os arquivos que você quer versionar:

```
git add nome_do_arquivo
```
