## **Git**

O **Git** é um sistema de controle de versão que ajuda a manter o seu código organizado, permite voltar a versões anteriores, e facilita o trabalho em equipe.

### **O que é o Git?**

Git permite que você acompanhe as mudanças no seu código ao longo do tempo.

1. **Salvar o estado do seu código** em vários momentos (commits).
2. **Voltar para uma versão anterior** se algo der errado.
3. **Colaborar com outras pessoas** sem interferir no trabalho delas.

## **Comandos Básicos e importantes do Git**
### 1. Inicializar um Repositório

Para começar a usar o Git em um projeto, você precisa inicializar um repositório:

```
git init
```

### 2. Adicionar Arquivos Alterados ou Todos de uma vez
Adicione os arquivos que você quer versionar:

```
git add nome_do_arquivo
```

Todos os arquivos de uma vez:

```
git add .
```
### 3. Dar um Commit
Depois de adicionar os arquivos, salve as mudanças com um commit:

```
git commit -m "Descrição das mudanças feitas"
```

### 4. Verificação de Histórico de commits
Veja o histórico de commits:
```
git log
```

### 5. Voltar para uma Versão Anterior
Se caso precisar voltar para uma versao anterior do código:

```
git checkout <ID do commit>
```
Você pode encontrar o ID do commit no git log.
Obg.: Ao digitar git log entrara em um ambiente dentro do git um pouco diferente, se tiver dúvida, clique "Q" de "quit" para sair.

### 6. Trabalhar em Equipe com Branches
Crie uma nova branch para trabalhar em uma nova feature.
```
git checkout -b feature/nomeDaSuaFeature
```
Obs.: O código acima ao ser usado, vai entrar na sua branch chamada "feature/nomeDaSuaFeature" se ja estiver feita, se digitar o código sem ter criado a branch, o código criara uma branch para você. O termo "feature" é apenas um padrão que é necessario ao trabalhar com git e git hub.
